# 🏠 Egypt Real Estate Appraiser

A machine learning project that predicts real estate prices in Egypt based on property features such as location, size, type, and number of rooms.

---

## 📌 Project Overview

| Item | Detail |
|------|--------|
| **Objective** | Predict property prices (Million EGP) in the Egyptian real estate market |
| **Dataset** | ~16,000 cleaned property listings scraped from Egyptian real estate portals |
| **Best Model** | Gradient Boosting Regressor |
| **Best R² Score** | 0.4919 (test set) |
| **Deployment** | Streamlit interactive web app |

---

## 📊 Model Comparison Results

| Model | MAE (M EGP) | RMSE (M EGP) | R² Score | MAPE (%) | CV R² (5-fold) |
|-------|:-----------:|:------------:|:--------:|:--------:|:--------------:|
| Linear Regression | 4.554 | 6.014 | 0.3518 | 68.3% | 0.350 |
| Random Forest | 3.904 | 5.362 | 0.4847 | 55.0% | **0.516** |
| **Gradient Boosting** ✅ | **3.914** | **5.324** | **0.4919** | 56.9% | 0.510 |

> **Gradient Boosting** was selected as the production model for its highest test R² and lowest RMSE.

## ⚙️ Setup & Installation

### Prerequisites
- Python 3.9+
- pip

### 1. Clone the Repository
```bash
git clone https://github.com/<your-username>/egypt-real-estate-appraiser.git
cd egypt-real-estate-appraiser
```

### 2. Create Virtual Environment (Recommended)
```bash
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

---

## 🚀 Running the Project

### Step 1 — Train the Model
```bash
python train.py
```
This will:
- Load and preprocess `cleaned_data.csv`
- Train and evaluate 3 models (Linear Regression, Random Forest, Gradient Boosting)
- Print a comparison table
- Save the best model as `model.pkl`

### Step 2 — Launch the Web App
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`

## 📐 Features Used

| Feature | Description | Encoding |
|---------|-------------|----------|
| `size_sqm` | Property area in square meters | Numeric |
| `bedrooms_num` | Number of bedrooms | Numeric |
| `bathrooms` | Number of bathrooms | Numeric |
| `governorate` | Extracted from location string | Label Encoded |
| `property_type` | Apartment, Villa, Chalet, etc. | Label Encoded |
| `payment_method` | Cash or Installments | Label Encoded |
